# Stat

A dashboard number: muted label, big ExtraBold value, optional change with a trend arrow.

React: `<Stat label="Visits this week" value="1,284" change="+12%" hint="vs last week" />`. The sign of `change` picks the arrow; `invert` when going down is good (wait time, cancellations) so it shows green.

Usually inside a Card, in a Grid of 3–4.
