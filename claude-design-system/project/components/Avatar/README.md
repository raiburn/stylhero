# Avatar

A round picture or initials that identifies a person.

```html
<span class="sh-avatar" title="María López">ML</span>
```

React: `<Avatar name="María López" src={photoUrl} size="lg" />` from `@stylhero/ui`; without `src` it shows initials.

- Sizes `sm` (32), `md` (40), `lg` (56).
- Pair with the person's name in text; the avatar alone isn't enough to identify someone.
