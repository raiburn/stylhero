# ButtonGroup

Joins related secondary Buttons or IconButtons into one bar.

```html
<div class="sh-btn-group" role="group">
  <button class="sh-btn sh-btn--secondary">Day</button>
  <button class="sh-btn sh-btn--secondary">Week</button>
</div>
```

React: `<ButtonGroup>…</ButtonGroup>`. If exactly one item is "on" at a time, use ToggleGroup instead.
