# Breadcrumbs

Shows where a page sits. Parent pages are muted links; the current page is ink, semibold, not a link.

React: `<Breadcrumbs items={[{ label: "Home", href: "/" }, { label: "Customers", href: "/customers" }, { label: "Ana Ruiz" }]} />`.

Place above the page title. Skip it for apps only one level deep.
