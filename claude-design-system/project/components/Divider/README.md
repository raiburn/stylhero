# Divider

A 1px `line` rule between groups of content.

```html
<hr class="sh-divider">
<div class="sh-divider sh-divider--label" role="separator"><span>or</span></div>
<hr class="sh-divider sh-divider--vertical">
```

React: `<Divider />`, `<Divider label="or" />`, `<Divider orientation="vertical" />`.

Prefer space over dividers; use one only when two groups would otherwise blur together.
