# Spinner

A small loading indicator for waits under a few seconds.

```html
<span class="sh-spinner" role="status" aria-label="Loading"></span>
```

React: `<Spinner size="sm" label="Loading customers" />` from `@stylhero/ui`.

- Sizes `sm` (16), `md` (20), `lg` (32). Inside a button it takes the text color.
- For whole sections that load, prefer showing the layout with placeholder content over a lone spinner.
