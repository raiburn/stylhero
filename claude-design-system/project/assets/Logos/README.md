# Logos

Outlined SVGs; no font needed. `stylhero-wordmark.svg` is for light backgrounds (navy #173a7a letters, sky #3ba3e6 dot). `stylhero-wordmark-reverse.svg` is for navy or dark backgrounds (white letters, lemon #f5d23d dot). `stylhero-mark.svg` is the square app icon and favicon. Don't recolor or retype them.
